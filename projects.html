Django School Management System

The Django School Management System is a web-based application developed using the Django Framework to simplify and automate daily school administrative activities. The application provides separate modules for administrators, teachers, and students, making academic management efficient, secure, and user-friendly.

Project Objective

To develop an online school management system that automates student registration, attendance management, teacher management, course management, examination records, and result processing, thereby reducing manual work and improving efficiency.

Technologies Used

  • Python
  • Django Framework
  • HTML5
  • SQLite Database
  • Bootstrap

Key Features

  • Admin Login Authentication
  • Student Registration Module
  • Teacher Management

Automated Resume Grading System using NLP, ML & DL

The Automated Resume Grading System is an AI-powered web application developed to automate the resume screening process using Natural Language Processing (NLP), Machine Learning (ML), and Deep Learning (DL). The system extracts important information from uploaded resumes, analyzes multiple candidate attributes, and predicts a resume grade (A, B, C, or D) to assist recruiters in identifying qualified candidates quickly and accurately.

Project Objective

To develop an intelligent resume analysis system that automatically extracts resume information, evaluates candidate profiles using AI techniques, and provides accurate resume grading to simplify the recruitment process while reducing manual effort and bias.

Technologies Used

  • Python
  • HTML5
  • CSS3
  • JavaScript
  • Flask
  • Natural Language Processing (NLP)
  • Machine Learning
  • Deep Learning
  • XGBoost Classifier
  • TF-IDF
  • OCR (Tesseract)
  • SQLite

Key Features

  • Resume Upload Interface
  • PDF Text Extraction and OCR Support
  • Automatic Skill Extraction using NLP
  • Project and Certification Analysis
  • GitHub Repository Quality Evaluation
  • Resume Grade Prediction (A, B, C & D)
